SigmaGpt is an AI-powered chatbot built using the MERN stack and Groq API. It provides real-time AI responses with a clean, ChatGPT-inspired interface.

### Features
- Real-time AI response streaming
- Chat history management
- Create and delete conversations
- MongoDB integration for storing chats
- Markdown rendering and code syntax highlighting
- Responsive dark-themed UI

### Tech Stack
- **Frontend:** React.js, CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB Atlas
- **AI Integration:** Groq API
- **Libraries:** React Markdown, Highlight.js

### Getting Started
1. Clone the repository.
2. Install dependencies using `npm install` in both frontend and backend.
3. Configure your `.env` file with your MongoDB URI and Groq API key.
4. Start the backend and frontend servers.
5. Open the application in your browser.
